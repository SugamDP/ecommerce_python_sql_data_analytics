# Brazilian E-Commerce Data Analytics

## Project Overview

An end-to-end data analytics project exploring Brazilian e-commerce data using Python, SQL, and Jupyter Notebook. The goal is to analyze sales performance, customer behavior, order trends, and other business metrics to uncover actionable insights.

## Tech Stack

- **Python** — Data processing and analysis
- **SQL** — Data querying and analysis
- **Pandas** — Data manipulation
- **Jupyter Notebook** — Exploratory data analysis
- **Database** — MySQL

## Dataset

This project uses the [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce).

The dataset contains information about orders, customers, products, sellers, payments, reviews, and deliveries.

**Note:** Raw CSV files are excluded from this repository due to their size. Download the dataset from Kaggle and place the required files in the `archive/` directory before running the notebooks.

## Getting Started

1. Clone this repository.
2. Install Python and the required dependencies.
3. Download the dataset from Kaggle and extract the CSV files into `archive/`.
4. Configure your database connection if required.
5. Open the Jupyter notebooks and run the analysis.

## Key Objectives

- Analyze sales and order trends.
- Explore customer purchasing behavior.
- Investigate delivery performance.
- Use SQL to query and analyze e-commerce data.
- Extract meaningful business insights from the data.
